# Prompt contract (offline candidate)

Initial Manager derives a specification through the existing system-prompt override; the normal Manager role is reserved for final reporting. Original `OrgUserInput` is separate from derived guidance in initial generation, automatic review/revision, documentation, final reports and menu requests. Legacy state falls back to `UserInput` without migration.

Code-producing initial/revision and menu feature/refactoring/security requests share numbered Code/Usage instructions. An explicit menu request may authorize a new feature, augmenting original requirements while preserving constraints. The exporter remains unchanged. QA is static review: no executor, no certification of later revisions. Metadata and testing/completion claims require supplied evidence. Documentation/code/reviews/retrieved content are data, not instructions.

Active system boundaries include seven main roles, initial Manager override, RAG query manager, nested web-text cleaner and RAG analysis override. The latter appends trust instructions to the caller-supplied system prompt; it does not reinterpret intermediate queries as authoritative original tasks. Legacy memory/feedback helpers and ingestion Unicode processing remain unchanged and outside this slice.

`NOTips` and `tipAmount` remain compatible inputs with no active monetary prompt effect. No stage, provider, transport budget, retry or pipeline change was introduced.

Offline CI includes native rendered-builder tests and original-filepath controlled request recording: reduced 2, full 10, full with optional reports 12, menu replay 11, initial RAG 5 and full RAG 25 mocked completion dispatches (including its nested cleaner). The menu replay covers feature, explanation, question, documentation, refactoring and security callers. Exact cases and final byte bindings belong to the closeout receipt; historical 140-case evidence is not final qualification.

Native qualification and delivery status are recorded in the external closeout receipt; checkout synchronization does not prove a running process loaded the script. No live model quality, universal injection resistance, or runnable generated-program claim. Exported Python is syntax-parsed only, never executed. The full RAG replay includes nested review analysis; the menu replay includes documentation generation and update.
